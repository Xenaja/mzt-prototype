# МЗТ — Московский Завод Термопанелей

Кликабельный десктопный прототип сайта по утверждённому макету Figma.

**Посмотреть онлайн:** https://xenaja.github.io/mzt-prototype/
Открывать на компьютере, ширина окна от 1280 пикселей. Мобильная версия
в этот этап не входит.

## Что не лежит в репозитории

Работа опирается на исходники, которые сюда не попали — вместе они весят
около 550 МБ:

| Папка | Что это | Зачем нужна |
|---|---|---|
| `figma-export/` | эталонный снимок макета 1920×12092 и его SVG | сверка вёрстки с макетом (`compare_block.py`) |
| `source/` | выгрузки из Figma, оригиналы изображений, выгрузка товаров Тильды | пересборка картинок и данных каталога |
| `release/` | сборка и архив для заказчика | пересоздаются командой `python build.py` |

Без них прототип открывается и работает — не работают только сверка с макетом
и пересборка данных каталога.

## Как запустить

Прототип — статические файлы, сборка не нужна:
откройте `prototype/index.html` в браузере.

Собрать архив для заказчика:

```
python build.py
```

Скрипт снимет dev-метки, пересжмёт hero в WebP и положит zip в `release/`.

## Примечание про `source/figma-raw/`

Сырая выгрузка занимает 107 МБ. Проверено по хешам: **все 46 уникальных
фотографий из неё уже лежат в `figma-clean/`** побайтово теми же файлами,
плюс связь с макетом (node_id, экран, исходное имя) сохранена в `manifest.csv`.
Остальное — 37 МБ побайтовых дублей и 120 SVG-обрывков (куски векторов
размером до 2×3 пикселей, 237 КБ).

То есть для фотографий папка избыточна и её можно удалить, освободив 107 МБ,
ничего не потеряв. Оставлена на случай, если понадобится пересобрать разбор.

## Порядок работы над блоками

Перед вёрсткой каждой секции — `prototype/BLOCK-CHECKLIST.md`.
Он собран из ошибок, найденных при сверке первого экрана с эталоном:
что снимать из макета, чего не делать в CSS, как проверять результат.
Пропуск пунктов стоит переделок — проверено.
